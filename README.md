# Public Speaking Coach

A practical public speaking coach for daily shift start-ups. It includes a 30-day practice program, hands-free Drive Mode, event announcements from a bulletin photo or upload, auto-generated scripts you can share, and a leadership track for connecting with your team.

Open the live app: https://shekharnsharma.github.io/public-speaking-coach/

On iPhone, open the link in Safari, tap Share, then tap Add to Home Screen.
